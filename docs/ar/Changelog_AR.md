# سجل التغييرات — النسخة العربية

### 2026-07-22 — v3 (القفزة النوعية)

- **هندسة نموذج v3 جديدة** مع تحسينات كبيرة في جودة الصوت والمتانة:
  - زيادة سعة النموذج: رفع `hidden_channels` و`inter_channels` إلى 256، و`filter_channels` إلى 1024، و`n_layers` إلى 8.
  - تعزيز آلية الانتباه: زيادة `n_heads` إلى 4.
  - توسيع `kernel_size` إلى 5 وتغيير `resblock` إلى "2" مع تكوينات تمدد محسّنة.
  - إضافة `p_dropout = 0.1` لتحسين التعميم.
  - تفعيل `use_spectral_norm = true` لتثبيت تدريب الشبكات التوليدية.

- **تحسين معالجة البيانات للصوت عالي الدقة**:
  - تحديد `mel_fmax` لكل معدل عينة (32k → 16k، 40k → 20k، 48k → 24k) لملاءمة نطاق التردد.
  - زيادة `upsample_initial_channel` من 512 إلى 768 لتحسين جودة الإخراج.

- **استراتيجية تدريب محسّنة**:
  - رفع `c_mel` إلى 60 وخفض `c_kl` إلى 0.5.
  - إضافة `warmup_epochs = 10` وضبط `learning_rate` بحسب معدل العينة (5e-5 لـ32k، 4e-5 لـ40k، 3e-5 لـ48k).
  - ضبط `batch_size` حسب معدل العينة وقيود الذاكرة (8/6/4 لـ 32k/40k/48k على التوالي).
  - تمديد التدريب الافتراضي إلى 30000 epoch للتجارب الطويلة.

- **تحميل ديناميكي وإدارة ذاكرة ذكية**:
  - قراءة `model_version` و`sample_rate` من `config.json` لاختيار إعدادات النموذج تلقائياً.
  - ضبط تلقائي لقيم مثل `x_query` عند تشغيل v3/48k على بطاقات ≤6GB لتقليل استهلاك الذاكرة.
  - إضافة مسار احتياطي (fallback) لتحميل `v3/48k.json` إن لم يوجد ملف الإعداد المطلوب.

- **تحسينات عامة**:
  - تصحيح اسم الحقل `threhold` إلى `threshold` في ملفات الإعداد.
  - تسجيل إصدار النموذج ومعدل العينة عند بدء التشغيل لزيادة الشفافية.
  - إظهار تحذيرات تشغيلية لمستخدمي بطاقات ≤4GB بشأن الأداء.
